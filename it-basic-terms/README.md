## Exploring to learn

As an IT professional, you'll continually encounter new and unfamiliar terminology that you'll need to learn and absorb to do your job effectively. This is a fundamental skill that you'll utilize far beyond your time at General Assembly.

<div class="activity solo-exercise">
  <h2 class="title">Research basic terminology</h2>
  <span class="minutes">90 min</span>
</div>

Spend a few minutes researching each of the terms and technologies below. Feel free to take notes or even construct a mind map to help connect ideas. If you have the time, don't be afraid to explore topics related to these terms to cement your understanding.

### Hardware basics

- Computer Form factor (for example, ATX, microATX)
- Motherboard
- CPU (Central Processing Unit)
- RAM (Random Access Memory)
- Storage devices (HDD, SSD, NVMe)
- Power supply unit (PSU)
- BIOS/UEFI
- Peripheral devices (mouse, keyboard, printer)
- Input/output (I/O) ports (USB, HDMI, DisplayPort, and so on)
- Cooling systems (fans, heatsinks)

### Operating system fundamentals

- Operating system (OS)
- File system (for example, NTFS, APFS, FAT32)
- Command-line interface (CLI)
- Graphical user interface (GUI)
- Device driver
- Task Manager
- Control Panel / Settings (Windows)

### Computer boot process

- Boot device / boot order
- POST
- Bootloader
- System files

### Basic networking terms

- IP address
- MAC address
- Modem
- Router
- Switch
- Ethernet cable (Cat5e, Cat6)
- Wi-Fi (802.11 standards)

### Computer tools and maintenance

- Antistatic wrist strap (ESD strap)
- Antistatic mat
- Torx/Phillips screwdrivers
- Multimeter
- POST (Power-On Self-Test)
- Diagnostic LEDs
- Cable management
- Firmware
- Electrostatic discharge (ESD)
